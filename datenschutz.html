Hosting

Diese Website wird über GitHub Pages (GitHub Inc., USA) bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie Ihre IP-Adresse, um die Seite auszuliefern und vor Missbrauch zu schützen.

Kontaktformular

Wenn Sie das Kontaktformular nutzen, werden Ihre Angaben (Name, E-Mail, Anliegen, Nachricht) an unseren eigenen Server übermittelt, per E-Mail an uns weitergeleitet und ausschließlich zur Bearbeitung Ihrer Anfrage verwendet. Zum Schutz vor Spam wird Ihre IP-Adresse in pseudonymisierter Form (als Hash) höchstens eine Stunde lang gespeichert.

Schriftarten

Die Schriftarten werden lokal von diesem Server geladen. Es findet keine Verbindung zu Google oder anderen Drittanbietern statt.
